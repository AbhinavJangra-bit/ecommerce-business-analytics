# Data Notes

## Date Transformation

Transaction dates were shifted +2 years from the source data to reflect a current analysis window.

- `Sales Date`: shifted +24 months
- `Order Date`: shifted +24 months
- `Ship Date`: shifted +24 months
- `Year`: shifted +2 years
- `Date of Birth`: unchanged

All monetary values, quantities, and categorical data are unchanged from the original source data.

The original raw dataset is preserved separately and has not been modified.
